Privacy Policy

Last updated: 19 November 2026

This policy describes the current FactoryOps AI web/PWA and planned Capacitor mobile application. It is a product disclosure, not a substitute for legal review. The final operator must verify and update it before commercial distribution.

Information processed

  • Workspace account data: email address and authentication/session information when an operator-configured Supabase project is enabled.
  • Factory records: information users enter, import or create, which may include BOM, production, quality, inventory, supplier, maintenance, cost, action and risk records.
  • Local application data: language preference and records saved in browser local storage when cloud mode is not active.
  • Support information: details users choose to include when contacting project maintainers.

Where information is stored

In local mode, records remain in browser/device storage and are not automatically synchronized or backed up. Clearing browser data or changing devices can make local records unavailable.

In cloud mode, account and workspace records are sent to the Supabase project configured by the deploying operator. That project owner controls its hosting region, access, retention, backups and account configuration. Review applicable Supabase terms and privacy information before enabling cloud mode.

The public web application is hosted by GitHub Pages. Network requests may be processed under GitHub's own privacy and security terms. The current stylesheet also requests the DM Sans font from Google Fonts when network access is available.

Use and sharing

FactoryOps AI uses information entered to provide workspace, operational reporting, import/export and authentication features. This codebase does not implement advertising or a dedicated analytics SDK. Hosting and authentication providers may process technical data needed to deliver their services. The application does not provide a marketplace for selling workspace records.

Security and user responsibilities

Cloud access depends on the deploying operator configuring Supabase Row Level Security correctly. The repository includes a starter schema, but each deployment must test tenant isolation, roles, backups and account lifecycle. Never place a Supabase service-role key in a browser or mobile build. Do not enter highly sensitive personal, employee, customer or regulated information until the operator has completed required security and legal review.

Retention and deletion

Local records remain until the user clears browser storage or removes them in the application. Cloud records are retained in the operator's Supabase project according to its configuration and the operator's retention policy. Users should contact the workspace administrator or project operator for account and data deletion requests. Export important records and maintain independent backups before deleting data or changing storage modes.

Children

FactoryOps AI is a business productivity tool and is not designed for children.

Contact

For product support or privacy questions, use the project support issue tracker. Do not post passwords, access tokens, personal data or confidential factory information in public issues.
